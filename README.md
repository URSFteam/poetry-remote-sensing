# 《诗词遥感》电子版

> 中国古典诗词、现代先进遥感技术，二者竟然能够结合起来，有点意思。

本书是为无任何遥感背景的中学生以及大学生所撰写的科普书，从中你将在品味诗词的过程中，了解遥感的整个过程与体系。

_作者：李林源、黄华国_
